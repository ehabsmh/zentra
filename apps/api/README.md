# @zentra/api

NestJS backend for Zentra.

Do not start here if you are new to the repo. Use the root setup guide:

- [docs/SETUP.md](../../docs/SETUP.md)
- [docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md)

## Useful scripts (from this folder)

```bash
npm run start:dev    # watch mode
npm run prisma:migrate
npm test             # unit tests
npm run test:e2e     # HTTP tests
```

From the **repo root** you can use `npm run dev:api`, `npm run db:migrate`, and `npm run test:api`.
